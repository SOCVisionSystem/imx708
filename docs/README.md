# SOCVisionSystem Documentation

This directory contains the GitHub Pages site for the SOCVisionSystem
IMX708 camera ecosystem.

## Structure

```
docs/
├── index.md              # Main landing page
├── _config.yml           # GitHub Pages configuration
├── .nojekyll             # Disable Jekyll processing
├── projects/
│   ├── driver.md         # imx708-driver documentation
│   ├── server.md         # imx708-server documentation
│   └── gui.md            # imx708-gui documentation
└── guide/
    ├── contributing.md   # Contribution guide
    └── quickstart.md     # Quick start guide
```

## Viewing Locally

```bash
# Install Jekyll
gem install jekyll bundler

# Serve the site
cd docs
bundle exec jekyll serve
```

Or just open the Markdown files in your browser — they render fine on GitHub.
